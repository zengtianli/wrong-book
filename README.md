# 错题本 · wrong-book

iPhone app：把 <https://edu.tianli.cyou> 的练习页装在身上，**没网也能做题**；
错过的题按「题型」记账，复习时出**同类新题**而不是把原题再放一遍。

## 它做什么

| tab | 干什么 |
|---|---|
| **学习** | 学科 → 单元 → 课，从 `curriculum.yaml` 派生。点进去就是完整的练习引擎（判题 / 讲解 / 勋章 / 连击），离线可用 |
| **错题本** | 两层：**题型层**（这一类错过 N 次、订正 M/2）点「复习」出同类新题；**具体题层**（我当时错的那几道）只回看、不重做 |
| **我的** | 今天做了几题 / 还差几题、每日提醒、课程包版本、账号 |

## 为什么复习不重放原题

> 「为了防止记住答案，错的题目也要变下」

原题再放一遍只会让孩子把答案背下来，看着会了其实没会。所以错题本记的是**题型**，
复习时用同一个生成器现出一道新题（换数字、换选项、换文本）——
**连着一次做对 2 回才划掉**，一次蒙对不算学会。

数据结构里没有 `ans` 也没有 `options`，所以「重放原题」这条路在结构上就不存在。

## 装

```bash
bash install-to-iphone.sh     # 默认走 WiFi，不用插线
```

需要 `~/Edu` 在本机（页面从那儿组装进包，不进本仓）。

## 它不做什么

- **不算分**。刷题积分由页面自己走 `/api/practice`，每日上限在服务端。账本在另一个 app（`points-deck`）
- **不加题**。加题走 `~/Edu` 的 `bank.py add`
- **不存试卷档案**。`~/Edu/archive/` 里有孩子姓名、成绩、原图，打包时有 fail-closed 的 PII 门挡着
